# Phase 0 Architecture Spec: Cloud Builders Day Event Concierge (`.agents-cli-spec.md`)

- **Agent Name**: `event_concierge_coordinator`
- **Framework**: Google Agent Development Kit (`google-adk`) + `agents-cli`
- **Model**: `gemini-3-flash-preview`
- **Topology**: Coordinator (`event_concierge_coordinator`) delegating to two focused sub-agents:
  1. `catalog_specialist` (`search_workshops`, `check_seat_availability`)
  2. `booking_specialist` (`check_seat_availability`, `reserve_workshop_seat`)
- **Curated ADK Recipes Referenced (`google/adk-samples/core/python/`)**:
  - `rag-agent-search` — Zero-maintenance search grounding pattern
  - `cross-session-memory` — Short-term `session.state` vs. long-term `VertexAiMemoryBankService`
  - `ambient-expense-agent` — Human-in-the-loop approval gate for group bookings (`seats_requested >= 5`)
  - `safety-plugins` — Runner-wide input safety screening before tool execution
- **Deployment Target**: Prototype-first (`--prototype`), enhanced to `agent_runtime` (Vertex AI Agent Engine) or `cloud_run` (Google Cloud Run)
